# K. R. Kiruthick Kumar — Portfolio

A Vercel-ready personal portfolio built with Next.js, React and Tailwind CSS.

## 1. Install

```bash
npm install
```

## 2. Run locally

```bash
npm run dev
```

Open http://localhost:3000

## 3. Build

```bash
npm run build
```

## 4. Deploy to Vercel

### GitHub method
1. Create a new GitHub repository.
2. Upload this project.
3. Go to Vercel and import the GitHub repository.
4. Keep the default Next.js settings.
5. Click Deploy.

### Vercel CLI
```bash
npm i -g vercel
vercel
```
